# 📌 О проекте

**CacheCleaner** — это учебный проект, разработанный в рамках курсовой/дипломной работы в колледже. Программа предназначена для очистки временных файлов, которые со временем могут занимать значительный объём дискового пространства и замедлять работу системы.

Утилита работает в консольном режиме, использует гибкую систему пресетов (JSON) и поддерживает переменные окружения (например, `$WIN_USERS$`), что позволяет адаптировать очистку под разных пользователей и конфигурации системы.

> 📄 Полное описание проекта, включая преимущества и обоснование, доступно в файле [`documents/CollegeProjectDescription.docx`](documents/CollegeProjectDescription.docx).

# 🤑 Возможности

* 🧹 **Очистка временных файлов и кеша** по предварительно заданным путям.
* ⚙️ **Гибкая настройка через JSON-пресеты** (`presets.json`) и пользовательские пути (`UserPaths.json`).
* 🔄 **Проверка обновлений и загрузка пресетов** — поддержка динамического получения конфигурации.
* 📏 **Отображение размера папок** перед очисткой.
* 🧪 **Режим «сухого прогона»** (`--dry-run-only`) — сканирование и вывод списка файлов без удаления.
* 🌐 **Поддержка переменных окружения** (например, `$WIN_USERS$`) для динамического формирования путей.
* 🛠️ **Кроссплатформенная сборка через CMake** (основная целевая платформа — Windows).
* 📦 **Готовый установщик** на базе INNO Setup (`setup.iss`).

# 📦 Сборка и установка

### Требования

* Компилятор с поддержкой **C++17** (MSVC, MinGW, GCC, Clang)
* **CMake** версии 3.15 или выше
* (Опционально) **INNO Setup** — для сборки установщика

### Клонирование репозитория

**bash**

```
git clone --recursive https://github.com/SG123it/CacheCleaner.git
cd CacheCleaner
```

### Сборка через CMake

**bash**

```
cmake -B build -G "MinGW Makefiles"
cmake --build build
```

После сборки исполняемый файл `CacheCleaner` появится в папке `build/` (или `build/Release/` в зависимости от генератора).

### Установка (Windows)

Готовый установщик можно собрать с помощью INNO Setup, открыв файл `setup.iss`. Готовый дистрибутив будет создан в папке `Output/`.

# 📁 Конфигурация

* **`documents/presets.json`** — основной файл с предустановленными путями для очистки. (Скачивается из интернета)
* **`UserPaths.json`** — пользовательский файл с дополнительными путями (создаётся автоматически или вручную).

Пример `UserPaths.json`:

**json**

```
{
  "Paths": [
    "C:\\Users\\%USERNAME%\\AppData\\Local\\Temp",
    "C:\\Windows\\Temp"
  ]
}
```
